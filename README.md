# jmeese/site

Personal academic site.

## Files

- `index.html` — home / bio. 
- `talks.html` — talks index. See `talks/README.md` to add a deck.
- `publications.html` — generated from papers.bib. 
- `data/papers.bib` — publication data.
- `build_publications.py` — publication script. 
- `talks/reveal-themes/` — reveal.js themes
